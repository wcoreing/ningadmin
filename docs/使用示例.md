# 文件上传功能使用示例

## 1. 配置文件上传方式

### 本地存储配置示例

```yaml
# server/etc/app.yaml
Upload:
  Type: local
  MaxSize: 10
  AllowedTypes: ["jpg", "jpeg", "png", "gif", "webp", "pdf", "doc", "docx"]

FileDomain: http://localhost:8080
```

### 阿里云OSS存储配置示例

```yaml
# server/etc/app.yaml
Upload:
  Type: oss
  MaxSize: 50
  AllowedTypes: ["jpg", "jpeg", "png", "gif", "webp", "pdf", "doc", "docx", "xls", "xlsx"]

OSS:
  Endpoint: "oss-cn-hangzhou.aliyuncs.com"
  AccessKeyId: "LTAI5txxxxxxxxxxxxxxxx"
  AccessKeySecret: "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
  BucketName: "my-project-files"
  Domain: "https://cdn.myproject.com"
  BasePath: "uploads"
```

## 2. 前端使用示例

### Vue组件中使用文件上传

```vue
<template>
  <div>
    <el-upload
      :http-request="customUpload"
      :before-upload="beforeUpload"
      :on-success="handleSuccess"
      :on-error="handleError"
      drag
      multiple
    >
      <el-icon class="el-icon--upload"><upload-filled /></el-icon>
      <div class="el-upload__text">
        将文件拖到此处，或<em>点击上传</em>
      </div>
    </el-upload>
  </div>
</template>

<script setup>
import { uploadFile } from '@/api/common/upload'
import { ElMessage } from 'element-plus'

const customUpload = async (options) => {
  try {
    const formData = new FormData()
    formData.append('file', options.file)
    formData.append('category_id', '1') // 可选：指定分类ID
    
    const result = await uploadFile(formData)
    options.onSuccess(result)
  } catch (error) {
    options.onError(error)
  }
}

const beforeUpload = (file) => {
  // 文件大小检查（前端预检查，后端也会验证）
  const isLt10M = file.size / 1024 / 1024 < 10
  if (!isLt10M) {
    ElMessage.error('文件大小不能超过 10MB!')
    return false
  }
  
  // 文件类型检查
  const allowedTypes = ['image/jpeg', 'image/png', 'image/gif']
  if (!allowedTypes.includes(file.type)) {
    ElMessage.error('只支持 JPG、PNG、GIF 格式的图片!')
    return false
  }
  
  return true
}

const handleSuccess = (response) => {
  ElMessage.success('上传成功!')
  console.log('文件URL:', response.url)
  // 处理上传成功后的逻辑
}

const handleError = (error) => {
  ElMessage.error('上传失败: ' + error.message)
}
</script>
```

### JavaScript中直接调用API

```javascript
import { uploadFile } from '@/api/common/upload'

// 上传单个文件
async function uploadSingleFile(file, categoryId = '') {
  try {
    const formData = new FormData()
    formData.append('file', file)
    if (categoryId) {
      formData.append('category_id', categoryId)
    }
    
    const result = await uploadFile(formData)
    console.log('上传成功:', result)
    return result
  } catch (error) {
    console.error('上传失败:', error)
    throw error
  }
}

// 批量上传文件
async function uploadMultipleFiles(files, categoryId = '') {
  const uploadPromises = files.map(file => uploadSingleFile(file, categoryId))
  
  try {
    const results = await Promise.all(uploadPromises)
    console.log('批量上传成功:', results)
    return results
  } catch (error) {
    console.error('批量上传失败:', error)
    throw error
  }
}
```

## 3. 后端API使用示例

### 上传文件接口

```http
POST /api/files/upload
Content-Type: multipart/form-data

file: [文件数据]
category_id: 1 (可选)
```


## 4. 配置切换示例

### 从本地存储切换到OSS

1. 修改配置文件：

```yaml
# 原配置
Upload:
  Type: local

# 新配置
Upload:
  Type: oss

OSS:
  Endpoint: "oss-cn-hangzhou.aliyuncs.com"
  AccessKeyId: "your-key-id"
  AccessKeySecret: "your-key-secret"
  BucketName: "your-bucket"
  BasePath: "uploads"
```

2. 重启服务，新上传的文件将自动使用OSS存储

### 从OSS切换到本地存储

1. 修改配置文件：

```yaml
Upload:
  Type: local
```

2. 重启服务，新上传的文件将保存到本地

## 5. 错误处理示例

### 前端错误处理

```javascript
try {
  const result = await uploadFile(formData)
  // 上传成功
} catch (error) {
  if (error.response) {
    const { code, message } = error.response.data
    switch (code) {
      case 400:
        ElMessage.error('请求参数错误: ' + message)
        break
      case 413:
        ElMessage.error('文件太大，请选择较小的文件')
        break
      case 415:
        ElMessage.error('不支持的文件类型')
        break
      default:
        ElMessage.error('上传失败: ' + message)
    }
  } else {
    ElMessage.error('网络错误，请稍后重试')
  }
}
```

### 后端错误响应示例

```json
{
  "code": 400,
  "message": "不支持的文件类型",
  "data": null
}
```

## 6. 最佳实践

1. **文件大小限制**: 根据业务需求合理设置MaxSize，建议不超过50MB
2. **文件类型限制**: 只允许业务需要的文件类型，提高安全性
3. **OSS配置**: 使用RAM子账号，授予最小必要权限
4. **域名配置**: 生产环境建议配置CDN加速域名
5. **错误处理**: 前端和后端都要做好错误处理和用户提示
6. **文件命名**: 系统自动生成UUID文件名，避免文件名冲突
