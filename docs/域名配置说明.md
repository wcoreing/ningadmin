# 文件上传域名配置说明

## 概述

系统支持根据文件存储方式自动选择合适的域名来访问文件，实现智能的域名切换。

## 域名使用逻辑

### 1. 文件URL存储格式

- **本地存储文件**：数据库中存储相对路径，如 `/uploads/filename.jpg`
- **OSS存储文件**：数据库中存储完整URL，如 `https://bucket.oss-cn-hangzhou.aliyuncs.com/uploads/2024/01/15/filename.jpg`

### 2. 域名选择规则

系统在返回文件URL时会根据文件的存储类型自动选择对应的域名：

```go
// 伪代码示例
func buildFileURL(relativePath, storageType string) string {
    if (storageType == "oss") {
        // OSS文件，使用OSS域名
        return config.OSS.Domain + relativePath
    } else {
        // 本地文件，使用本地域名
        return config.FileDomain + relativePath
    }
}
```

**存储类型识别：**
- 新上传的文件：根据当前配置的Upload.Type自动设置存储类型
- 历史文件：系统自动根据URL格式判断存储类型（向后兼容）

### 3. 配置示例

#### 本地存储模式配置

```yaml
# server/etc/app.yaml
Upload:
  Type: local
  
FileDomain: http://localhost:8080

# 或者生产环境
FileDomain: https://api.yourdomain.com
```

**文件访问示例：**
- 数据库存储：`/uploads/abc123.jpg` (相对路径)
- 存储类型：`local`
- 访问URL：`http://localhost:8080/uploads/abc123.jpg`

#### OSS存储模式配置

```yaml
# server/etc/app.yaml
Upload:
  Type: oss
  
OSS:
  Endpoint: "oss-cn-hangzhou.aliyuncs.com"
  BucketName: "my-bucket"
  Domain: "https://cdn.yourdomain.com"  # 可选CDN域名
  
FileDomain: http://localhost:8080  # 用于本地历史文件
```

**文件访问示例：**
- OSS文件：
  - 数据库存储：`/uploads/2024/01/15/abc123.jpg` (相对路径)
  - 存储类型：`oss`
  - 访问URL：`https://cdn.yourdomain.com/uploads/2024/01/15/abc123.jpg`
- 本地历史文件：
  - 数据库存储：`/uploads/old-file.jpg` (相对路径)
  - 存储类型：`local`
  - 访问URL：`http://localhost:8080/uploads/old-file.jpg`

## 混合存储场景

系统支持混合存储场景，即数据库中同时存在本地文件和OSS文件：

### 场景1：从本地存储切换到OSS

```yaml
# 原配置（已有本地文件）
Upload:
  Type: local

# 新配置（新文件使用OSS）
Upload:
  Type: oss
OSS:
  Endpoint: "oss-cn-hangzhou.aliyuncs.com"
  BucketName: "my-bucket"
  Domain: "https://cdn.yourdomain.com"
```

**结果：**
- 历史本地文件：`http://localhost:8080/uploads/old-file.jpg`
- 新OSS文件：`https://cdn.yourdomain.com/uploads/2024/01/15/new-file.jpg`

### 场景2：从OSS切换到本地存储

```yaml
# 原配置（已有OSS文件）
Upload:
  Type: oss

# 新配置（新文件使用本地）
Upload:
  Type: local
FileDomain: http://localhost:8080
```

**结果：**
- 历史OSS文件：`https://cdn.yourdomain.com/uploads/2024/01/15/old-file.jpg`
- 新本地文件：`http://localhost:8080/uploads/new-file.jpg`

## 域名配置最佳实践

### 1. 本地开发环境

```yaml
Upload:
  Type: local
FileDomain: http://localhost:8080
```

### 2. 测试环境

```yaml
Upload:
  Type: local
FileDomain: https://test-api.yourdomain.com
```

### 3. 生产环境 - 本地存储

```yaml
Upload:
  Type: local
FileDomain: https://api.yourdomain.com
```

### 4. 生产环境 - OSS存储

```yaml
Upload:
  Type: oss
OSS:
  Endpoint: "oss-cn-hangzhou.aliyuncs.com"
  BucketName: "prod-files"
  Domain: "https://cdn.yourdomain.com"  # CDN加速域名
  
FileDomain: https://api.yourdomain.com  # 用于历史本地文件
```

## 注意事项

1. **FileDomain配置**：
   - 即使使用OSS存储，也建议保留FileDomain配置
   - 用于访问历史的本地存储文件
   - 确保域名地址正确且可访问

2. **OSS Domain配置**：
   - 可以配置CDN加速域名提高访问速度
   - 如果不配置，系统会使用OSS默认域名
   - 确保域名已在阿里云控制台正确绑定

3. **HTTPS支持**：
   - 生产环境建议使用HTTPS协议
   - 确保所有域名都支持HTTPS访问

4. **跨域配置**：
   - 如果前后端分离部署，注意配置CORS
   - 确保文件域名允许前端域名访问

## 常见问题

### Q: 切换存储方式后历史文件无法访问？
A: 检查FileDomain配置是否正确，系统会自动根据URL格式选择合适的域名。

### Q: OSS文件访问很慢？
A: 配置CDN加速域名，在OSS.Domain中设置CDN地址。

### Q: 本地文件404错误？
A: 检查FileDomain配置和静态文件服务是否正确配置。

### Q: 可以同时使用多个OSS域名吗？
A: 系统会根据数据库中存储的完整URL返回，支持历史文件使用不同域名。
