# 配置结构升级说明

## 概述

本次升级调整了 `app.yaml` 配置文件的结构，将阿里云相关配置统一整理到 `aliyun` 节点下，使配置更加清晰和规范。

## 主要变更

### 1. 配置结构调整

**升级前（旧结构）：**
```yaml
Upload:
  Type: oss
  MaxSize: 10
  AllowedTypes: ["jpg", "jpeg", "png"]

OSS:
  Endpoint: "oss-cn-beijing.aliyuncs.com"
  AccessKeyId: "your-access-key-id"
  AccessKeySecret: "your-access-key-secret"
  BucketName: "your-bucket"
  Domain: "https://your-domain.com"
  BasePath: "uploads"
```

**升级后（新结构）：**
```yaml
Upload:
  Type: oss
  MaxSize: 10
  AllowedTypes: ["jpg", "jpeg", "png"]

aliyun:
  oss:
    endpoint: "oss-cn-beijing.aliyuncs.com"
    accessKeyId: "LTAI5tEgge2T7tWCRERpE8Pe"
    accessKeySecret: "3EOStSzghEcdnHIul3xQVTFgpdMuWP"
    bucketName: "blog-page"
    domain: "https://blog-page.oss-cn-beijing.aliyuncs.com"
    basePath: "uploads"
  sms:
    accessKeyId: "LTAI5tPdEbKwLWf1dRm47HJn"
    accessKeySecret: "v8VemElWRj2Oy8y4vjNj0dEApYaOv4"
    signName: "赤县门生实习平台"
    templateCode:
      register: "SMS_266885365"
      login: "SMS_266885365"
      resetPassword: "SMS_266885365"
```

### 2. 代码结构调整

**配置访问方式变更：**

```go
// 升级前
config.App.OSS.Endpoint
config.App.OSS.AccessKeyId
config.App.OSS.AccessKeySecret

// 升级后
config.App.Aliyun.OSS.Endpoint
config.App.Aliyun.OSS.AccessKeyId
config.App.Aliyun.OSS.AccessKeySecret
```

### 3. 新增SMS配置支持

现在支持阿里云短信服务配置：

```go
// SMS配置访问
config.App.Aliyun.SMS.AccessKeyId
config.App.Aliyun.SMS.AccessKeySecret
config.App.Aliyun.SMS.SignName
config.App.Aliyun.SMS.TemplateCode.Register
config.App.Aliyun.SMS.TemplateCode.Login
config.App.Aliyun.SMS.TemplateCode.ResetPassword
```

## 升级步骤

### 1. 更新配置文件

将现有的 `server/etc/app.yaml` 文件按照新结构进行调整：

1. 将 `OSS` 节点移动到 `aliyun.oss` 下
2. 将字段名改为小写（遵循yaml规范）
3. 可选：添加SMS配置

### 2. 字段映射对照表

| 旧字段 | 新字段 |
|--------|--------|
| `OSS.Endpoint` | `aliyun.oss.endpoint` |
| `OSS.AccessKeyId` | `aliyun.oss.accessKeyId` |
| `OSS.AccessKeySecret` | `aliyun.oss.accessKeySecret` |
| `OSS.BucketName` | `aliyun.oss.bucketName` |
| `OSS.Domain` | `aliyun.oss.domain` |
| `OSS.BasePath` | `aliyun.oss.basePath` |

### 3. 无需代码变更

本次升级已经完成了所有相关代码的调整，包括：

- `server/app/config/app.go` - 配置结构定义
- `server/app/common/utils/oss_utils.go` - OSS工具类
- `server/app/service/common/file/file_service.go` - 文件服务

### 4. 兼容性说明

- ✅ 完全向后兼容，无需修改现有业务代码
- ✅ 数据库结构无变更
- ✅ API接口无变更
- ✅ 前端代码无需修改

## 升级验证

升级完成后，可以通过以下方式验证：

1. **编译检查**：
   ```bash
   cd server
   go build -o test.exe .
   ```

2. **功能测试**：
   - 文件上传功能正常
   - OSS存储正常工作
   - 配置读取正确

3. **日志检查**：
   启动服务后检查是否有配置相关的错误日志

## 注意事项

1. **备份配置**：升级前请备份原有配置文件
2. **重启服务**：配置文件修改后需要重启服务
3. **权限验证**：确保新配置的访问密钥有效
4. **环境一致**：各环境配置文件都需要相应调整

## 优势

1. **结构清晰**：阿里云相关配置统一管理
2. **易于扩展**：后续可方便添加其他阿里云服务
3. **规范统一**：遵循yaml配置规范
4. **便于维护**：配置层次结构更加合理

这次配置结构升级使系统配置更加规范和易于维护，为后续功能扩展奠定了良好基础。
