## 中间件函数说明

### WithSelect(module, action)
用于查询类操作，记录查询行为

### WithCreate(module, action)
用于新增类操作，记录创建行为

### WithUpdate(module, action)
用于更新类操作，记录修改行为

### WithDelete(module, action)
用于删除类操作，记录删除行为

## 使用示例

```go
// 查询操作
userGroup.GET("/list", middleware.WithSelect("用户管理", "查询用户列表"), userController.List)

// 新增操作
userGroup.POST("", middleware.WithCreate("用户管理", "新增用户"), userController.Add)

// 更新操作
userGroup.PUT("", middleware.WithUpdate("用户管理", "修改用户"), userController.Update)

// 删除操作
userGroup.DELETE("/:id", middleware.WithDelete("用户管理", "删除用户"), userController.Delete)
```

## 注意事项

1. 所有需要记录操作日志的路由都已配置中间件
2. 公开路由（如登录、静态资源）不记录操作日志
3. 操作日志会自动记录：用户信息、操作时间、请求参数、响应结果等
4. 前端部门选项API路径已调整为 `/system/dept/options`
