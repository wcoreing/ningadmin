# 文件上传功能升级说明

## 🚀 功能概述

系统已升级为智能文件上传功能，支持根据配置动态选择存储方式和域名。所有文件在数据库中统一存储相对路径，在访问时根据文件的存储类型自动选择对应的域名。

## 📊 核心改进

### 1. 统一存储格式
- **数据库存储**：所有文件统一存储相对路径（如：`/uploads/2024/01/15/file.jpg`）
- **存储类型标识**：新增`storage_type`字段标识文件存储位置（`local`或`oss`）
- **智能域名切换**：根据存储类型自动选择对应域名

### 2. 配置驱动
```yaml
# 本地文件域名
FileDomain: http://localhost:8080

# OSS文件域名
OSS:
  Domain: "https://your-bucket.oss-cn-hangzhou.aliyuncs.com"
```

### 3. 向后兼容
- 支持历史数据的自动识别和处理
- 无需手动迁移历史文件
- 平滑升级，不影响现有功能

## 🔧 技术实现

### 数据库结构变更
```sql
-- 添加存储类型字段
ALTER TABLE `sys_file` ADD COLUMN `storage_type` varchar(20) NOT NULL DEFAULT 'local' COMMENT '存储类型(local:本地 oss:阿里云OSS)' AFTER `type`;
```

### 文件存储逻辑
```go
// 本地文件
数据库存储: "/uploads/file.jpg"
存储类型: "local"
访问URL: config.FileDomain + "/uploads/file.jpg"

// OSS文件  
数据库存储: "/uploads/2024/01/15/file.jpg"
存储类型: "oss"
访问URL: config.OSS.Domain + "/uploads/2024/01/15/file.jpg"
```

### 智能域名选择
```go
func buildFileURL(relativePath, storageType string) string {
    if storageType == "oss" {
        return config.OSS.Domain + relativePath
    } else {
        return config.FileDomain + relativePath
    }
}
```

## 📝 配置说明

### 完整配置示例
```yaml
Name: wnadmin
Host: 0.0.0.0
Port: 8080
ENV: dev
FileDomain: http://localhost:8080  # 本地文件访问域名

# 文件上传配置
Upload:
  Type: oss  # 当前上传方式: local 或 oss
  MaxSize: 50
  AllowedTypes: ["jpg", "jpeg", "png", "gif", "webp", "pdf"]

# 阿里云OSS配置
OSS:
  Endpoint: "oss-cn-hangzhou.aliyuncs.com"
  AccessKeyId: "your-access-key-id"
  AccessKeySecret: "your-access-key-secret"
  BucketName: "your-bucket-name"
  Domain: "https://cdn.yourdomain.com"  # OSS文件访问域名
  BasePath: "uploads"
```

### 域名配置说明
1. **FileDomain**: 本地文件访问域名
   - 用于本地存储的文件访问
   - 即使使用OSS，也要保留此配置（用于历史本地文件）

2. **OSS.Domain**: OSS文件访问域名
   - 可以是OSS默认域名
   - 可以是绑定的CDN加速域名
   - 只在使用OSS时需要配置

## 🔄 升级步骤

### 1. 数据库升级
执行SQL脚本添加`storage_type`字段：
```bash
mysql -h 127.0.0.1 -u root -p123456 wnsys < docs/sql/add_storage_type.sql
```

### 2. 配置文件更新
更新`server/etc/app.yaml`配置文件，添加OSS域名配置。

### 3. 重启服务
重启后端服务，新配置生效。

## 🌟 使用场景

### 场景1：纯本地存储
```yaml
Upload:
  Type: local
FileDomain: http://localhost:8080
```
**结果**: 所有文件使用本地存储和本地域名

### 场景2：纯OSS存储
```yaml
Upload:
  Type: oss
OSS:
  Domain: "https://cdn.yourdomain.com"
FileDomain: http://localhost:8080  # 保留用于历史文件
```
**结果**: 新文件使用OSS存储和OSS域名，历史本地文件仍可访问

### 场景3：混合存储
数据库中同时存在本地文件和OSS文件，系统自动根据存储类型选择对应域名。

## ✅ 优势特性

1. **配置驱动**: 通过配置文件控制上传方式和域名
2. **智能切换**: 自动根据存储类型选择域名
3. **向后兼容**: 支持历史数据无缝迁移
4. **性能优化**: CDN加速支持，提升访问速度
5. **扩展性强**: 易于添加其他存储方式

## 🚨 注意事项

1. **域名配置**: 确保配置的域名可正常访问
2. **权限设置**: OSS存储桶需要公共读权限
3. **HTTPS支持**: 生产环境建议使用HTTPS
4. **数据备份**: 升级前建议备份数据库

## 🐛 故障排除

### 问题1: 文件访问404
**原因**: 域名配置错误或存储类型识别错误
**解决**: 检查配置文件中的域名设置

### 问题2: 历史文件无法访问
**原因**: 数据库迁移未完成
**解决**: 执行SQL脚本更新`storage_type`字段

### 问题3: OSS文件上传失败
**原因**: OSS配置错误或权限不足
**解决**: 检查OSS配置参数和访问权限
