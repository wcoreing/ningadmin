# 文件上传配置说明

本系统支持两种文件上传方式：本地存储和阿里云OSS存储。

## 配置说明

在 `server/etc/app.yaml` 文件中进行配置：

```yaml
# 文件上传配置
Upload:
  Type: local  # 上传方式: local(本地) 或 oss(阿里云OSS)
  MaxSize: 10  # 最大文件大小(MB)
  AllowedTypes: ["jpg", "jpeg", "png", "gif", "webp", "pdf", "doc", "docx", "xls", "xlsx", "ppt", "pptx", "txt", "zip", "rar"]

# 阿里云OSS配置 (当Upload.Type为oss时生效)
OSS:
  Endpoint: "oss-cn-hangzhou.aliyuncs.com"        # OSS访问域名，根据你的区域修改
  AccessKeyId: "your-access-key-id"               # 你的AccessKey ID
  AccessKeySecret: "your-access-key-secret"       # 你的AccessKey Secret
  BucketName: "your-bucket-name"                  # 你的存储空间名称
  Domain: ""                                      # 自定义域名（可选，如果配置了CDN域名）
  BasePath: "uploads"                             # 文件存储基础路径
```

## 配置参数详解

### Upload 配置

- **Type**: 上传方式
  - `local`: 本地存储，文件保存在服务器本地
  - `oss`: 阿里云OSS存储，文件保存在阿里云对象存储中

- **MaxSize**: 最大文件大小限制，单位为MB

- **AllowedTypes**: 允许上传的文件类型列表

### OSS 配置（仅当Type为oss时需要）

- **Endpoint**: OSS访问域名，根据你的存储桶所在区域设置
  - 华东1（杭州）：`oss-cn-hangzhou.aliyuncs.com`
  - 华北2（北京）：`oss-cn-beijing.aliyuncs.com`
  - 华东2（上海）：`oss-cn-shanghai.aliyuncs.com`
  - 更多区域请参考阿里云OSS文档

- **AccessKeyId**: 阿里云访问密钥ID

- **AccessKeySecret**: 阿里云访问密钥Secret

- **BucketName**: OSS存储桶名称

- **Domain**: 自定义域名（可选）
  - 如果配置了CDN加速域名，可以填写此项
  - 留空则使用OSS默认域名

- **BasePath**: 文件存储的基础路径，文件会按日期分目录存储
  - 例如：`uploads/2024/01/15/filename.jpg`

## 使用方式

### 本地存储模式

```yaml
Upload:
  Type: local
  MaxSize: 10
  AllowedTypes: ["jpg", "jpeg", "png", "gif", "webp"]
```

文件将保存在 `server/uploads/` 目录下，通过 `FileDomain` 配置的域名访问。

### OSS存储模式

```yaml
Upload:
  Type: oss
  MaxSize: 10
  AllowedTypes: ["jpg", "jpeg", "png", "gif", "webp"]

OSS:
  Endpoint: "oss-cn-hangzhou.aliyuncs.com"
  AccessKeyId: "LTAI5txxxxxxxxxxxxxxxx"
  AccessKeySecret: "xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
  BucketName: "my-bucket"
  Domain: "https://cdn.example.com"  # 可选
  BasePath: "uploads"
```

文件将上传到阿里云OSS，通过OSS域名或自定义域名访问。

## 注意事项

1. **安全性**: 请妥善保管阿里云AccessKey，建议使用RAM子账号并授予最小权限
2. **权限设置**: 确保OSS存储桶有公共读权限，否则文件无法正常访问
3. **域名配置**: 如果使用自定义域名，需要在阿里云控制台绑定域名并配置CNAME
4. **文件大小**: 根据实际需求调整MaxSize，过大可能影响上传体验
5. **文件类型**: 根据业务需求配置AllowedTypes，建议只允许必要的文件类型

## 切换上传方式

系统支持动态切换上传方式，只需修改配置文件中的 `Upload.Type` 参数：

- 从本地切换到OSS：修改 `Type: oss` 并配置OSS参数
- 从OSS切换到本地：修改 `Type: local`

**注意**: 切换上传方式不会影响已上传的文件，但新上传的文件将使用新的存储方式。
